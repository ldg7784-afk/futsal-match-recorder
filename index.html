보안 및 클라우드(DB) 연동 설계 가이드

1. 권장 관리형 클라우드 데이터베이스 (Supabase / Firebase)

여러 기기에서 동일한 경기 기록을 실시간 공유하거나 중앙 관리가 필요한 경우, 무료 티어로 시작할 수 있는 Supabase(PostgreSQL 기반, RLS 보안 규칙 제공) 또는 Firebase Firestore를 권장합니다.

2. 권한 및 보안 규칙 (Row Level Security)

  • 학생 권한: 자신이 생성한 경기 세션의 기록만 INSERT/UPDATE 가능.
  • 교사 권한: 교사 인증(JWT role: 'teacher')을 거쳐 전체 경기 세션 열람 및 삭제 가능.
  • 화면 숨김이 아닌 DB 레벨 강제: RLS 정책을 통해 비인가된 접근을 데이터베이스 단계에서 직접 차단합니다.

3. 비밀키 및 개인정보 보호

  • API Key 및 Service Role Secret은 코드 내 하드코딩 금지 (환경변수 .env 처리).
  • 전송 구간 HTTPS(TLS) 의무 적용 및 학생 식별 정보 마스킹 기능 제공.
