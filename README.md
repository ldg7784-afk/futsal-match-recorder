# 스마트 체육 경기 기록 시스템 (Futsal Match Recorder)

> 방과후/동아리 풋살 및 체육 경기 중 학생이 **15분 경기 타이머**에 맞춰 **선수별 득점·어시스트·파울**을 빠르고 정확하게 기록하고, **이름·학번 자동 연동**으로 오타를 방지하며 수업이 끝나도 기록이 보존되는 웹 애플리케이션입니다.

---

## 1. 기술 방향 및 아키텍처 제안

### A. 기술 스택 선정 이유
- **프론트엔드**: HTML5, Vanilla Modern CSS, ES6+ JavaScript
  - **이유**: 별도의 복잡한 빌드 과정(`npm install`, 번들러 설정 등) 없이 학교 컴퓨터나 태블릿, 스마트폰 브라우저에서 즉시 열어 사용할 수 있도록 가장 경량화되고 신뢰성 높은 바닐라 웹 기술을 적용했습니다.
  - **반응성 최적화**: 15분 경기 타이머가 돌아가는 중에도 터치/클릭 즉시 DOM 부분 갱신 및 디바운스 자동 저장(300ms)을 수행하여 끊김 현상이 전혀 없습니다.

### B. 관리형 데이터베이스 연동 제안 (Supabase vs Firebase)
여러 학생과 교사가 서로 다른 기기에서 실시간으로 경기 기록을 공유하고 조회해야 할 경우, **Supabase**를 권장합니다.
- **추천**: **Supabase (PostgreSQL 기반)**
  - **선정 이유**: 무료 티어 제공, 브라우저에서 직접 연동 가능한 JS SDK, 강력한 **행 단위 보안(Row Level Security, RLS)** 지원.
  - **보안 규칙 예시**:
    ```sql
    -- 학생은 자신의 세션 기록만 삽입/수정 가능
    CREATE POLICY "Students can insert own session" 
    ON player_records FOR INSERT 
    WITH CHECK (auth.uid() = student_id);

    -- 교사는 전체 세션 열람 가능
    CREATE POLICY "Teachers can view all" 
    ON player_records FOR SELECT 
    USING (auth.jwt() ->> 'role' = 'teacher');
    ```

## 3. 핵심 7대 기능 모듈

| 모듈 | 역할 | 주요 기능 |
| :--- | :--- | :--- |
| **모듈 1: 화면/UI** | 입력 반응성 극대화 | 선수 카드 그리드, 득점(⚽)·도움(👟)·파울(⚠️) 증감 버튼, A/B팀 종합 스코어 집계 |
| **모듈 2: 학생 자동 연동** | 오타 방지 및 식별 | 이름 입력 시 학번 자동 추천, 학번 입력 시 이름 자동완성, 개인정보 가명(마스킹) 옵션 |
| **모듈 3: 15분 경기 타이머** | 경기 시간 정밀 측정 | 15:00 카운트다운, 시작/일시정지/리셋/+1분/+5분, `Date.now()` 드리프트 보정 및 새로고침 복원 |
| **모듈 4: 기록 영속화** | 다음 수업에서도 유지 | 입력 즉시 LocalStorage 자동 저장, 경기 세션 ID 발급, 과거 세션 불러오기 |
| **모듈 5: 교사 관리 모드** | 교사 확인 및 감사 | 전체 경기 세션 이력 조회, 세션별 통계, 전체 데이터 JSON 백업/복원 및 영구 파기 |
| **모듈 6: 개인정보보호** | 최소 수집 및 안전 처리 | 이름·학번 외 불필요 정보 배제, 실명 마스킹(김*준), 비밀키 분리 원칙 |
| **모듈 7: 심의 대응 문서** | 학교 심의 규정 대응 | 개인정보 처리방침 및 이용약관 모달 뷰, 목적 구분(수업/동아리/행정) 셀렉터 |

## 4. 바로 실행하는 방법

### 방법 1. 웹 브라우저에서 바로 열기
1. 탐색기에서 `c:\Users\user\Desktop\footsal\index.html` 파일을 더블클릭합니다.
2. 크롬, 엣지, 웨일 등 최신 브라우저에서 즉시 실행됩니다.

### 방법 2. 로컬 웹 서버 실행 (추천)
Node.js 또는 Python이 설치되어 있는 경우:
```bash
# Node.js http-server 또는 npx 이용 시
npx -y serve .

# 또는 Python 내장 서버 이용 시
python -m http.server 8080
```
브라우저에서 `http://localhost:8080` (또는 터미널에 표시된 포트)로 접속합니다.

## 5. 학교 심의 및 운영 시 주의사항 (선생님 체크리스트)

1. **자리표시자(`[ ]`) 수정 안내**:
   - `PRIVACY_POLICY.md` 및 `TERMS_OF_SERVICE.md` 문서 내의 `[학교명]`, `[담당교사 연락처]`, `[보관기한]` 등을 학교 규정에 맞게 실제 값으로 교체하여 최종 승인받으시기 바랍니다.
2. **학생 데이터 사전 등록**:
   - `students.json` 파일에 학급 또는 동아리 학생들의 학번과 이름을 입력해 두면, 수업 시작 1분 안에 오타 없이 빠르고 정확하게 자동완성이 작동합니다.
3. **학기말 데이터 파기**:
   - 학기 또는 학년도가 종료되면 상단 **[교사 관리 모드]**에서 **[전체 데이터 영구 삭제]**를 눌러 개인정보를 안전하게 파기할 수 있습니다.
