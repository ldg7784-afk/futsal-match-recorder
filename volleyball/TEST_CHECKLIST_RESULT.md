## 2. 기능 및 비기능 체크리스트 검증

- [x] **교사용 루브릭 기반 점수 입력**: 4대 평가 항목(언더핸드 패스, 오버핸드 패스, 서브, 규칙·팀워크)별 A~D 등급 클릭 또는 직접 점수 입력 지원
- [x] **입력값 유효성 검증 (`ValidationModule`)**: 필수 항목 누락 및 허용 점수 범위(`10~25점`) 초과/미달 시 구체적인 한국어 오류 안내 및 저장 버튼 비활성화
- [x] **저장 즉시 학생 화면 반영**: `BroadcastChannel` + `LocalStorage` 동기화로 교사가 저장하는 즉시 학생 화면 총점 및 아코디언에 0ms 반영
- [x] **학생용 총점 큰 숫자 표시**: 학생 화면 최상단에 초대형 숫자(`5.2rem`)로 총점 강조 표시
- [x] **학생용 아코디언 1회 클릭 즉시 동작**: 각 항목 클릭 시 지연 없이 즉시 펼치기/접기 전환 (전체 펼치기/전체 접기 포함)
- [x] **제외 범위 준수**: 영상 업로드, 동작 체크리스트, 점수 이력, 학생 재제출, 알림 기능 완전히 제외
- [x] **심의 및 정책 대응**: 사용 목적 체크리스트(교사 단독/정규 수업/가정 과제/개인정보 마스킹 모드), 개인정보 처리방침 초안, 이용약관 초안, 하단 푸터 5대 필수 링크 포함
